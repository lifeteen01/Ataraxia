Rust Lite

The information half of the Rust client. You see players, loot and events; your aim stays yours. Cheaper, and the module you are most likely to keep switched on anyway.

  • Players
  • World
  • Events
  • Radar
  • Profiles

What is in it

Every module is optional and starts switched off. Nothing is preconfigured, because a default that stands out is worse than no feature at all.

Players

Boxes, skeletons, health, held weapon and distance. Teammates, sleepers, scientists and animals each get their own filter and colour, so a sleeping player never reads the same as a live one.

World

Ore nodes, hemp, barrels, dropped items, stashes and traps. Every category has its own distance cutoff, so the screen holds what is worth walking to and nothing else.

Events

Airdrop, patrol helicopter, Bradley and cargo, each with a timer. You know what is inbound before you hear it, and where it lands before the parachute opens.

Radar

The local overlay from the front page: detection range, heading that follows you, corner placement and a size you set once. Teammates and players are drawn separately.

Profiles

Save a full set of settings per situation, switch mid-wipe with a shortcut you choose, and export the file if you want to hand it to a friend.
